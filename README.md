# LensLoom

LensLoom enables real-time data aggregation across distributed nodes, leveraging microservices architecture and auto-scaling for modular, highly available components.

LensLoom is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/LensLoom.git`
2. `cd LensLoom`
3. Install in editable mode: `pip install -e .`

## Configuration

LensLoom is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
